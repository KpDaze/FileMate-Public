# FileMate working rules

This is the public native Android copy in KpDaze/FileMate-Public. Preserve unrelated repositories and the hosted phone preview. Follow the user's full handover and approved blue design; README.md and docs record the agreed milestones and Drive defaults.

- Local-first Kotlin/Compose. No paid/metered dependencies or paid hosted build service without approval. Optional Google Drive must not underpin core functionality.
- Source checkpoints go to this repo promptly. Verify durable APK and private signing backup saves before claiming delivery is ready. Never commit keys/passwords, SDKs, caches or personal files.
- Preserve history. No force-pushing, unrelated repo changes or destructive database upgrades.
- Finite event-based monitoring, normal app switching, automatic inactivity stop and reopen catch-up. Never poll Downloads or claim source certainty from timing alone.
- Low-confidence files stay untouched. Bulk changes preview first, no auto-deletion, conservative camera handling, Activity/Undo where supported. Never delete local files before verified Drive upload.
- Keep the full Version 1 target. The first technical proof is not the completed organiser/gallery.
- Distinguish build/unit-test evidence from emulator and real-phone evidence. Do not claim unperformed device tests passed.
- The user works from Android and does not code. No IDE or terminal required from them; explain steps plainly and do not re-request already granted permission.
